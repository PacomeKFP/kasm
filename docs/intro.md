# Langage Pseudo-Assembleur

Bienvenue dans la documentation du **Pseudo-Assembleur** - un langage éducatif simplifié pour découvrir la programmation bas niveau.

## Caractéristiques clés
- Manipulation directe de la mémoire
- 4 types d'instructions différents
- Gestion du flux de contrôle
- Modèles de mémoire simples
